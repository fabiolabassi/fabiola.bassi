# Justificativa — Questão 03

O compomente Task define precisamente o entregável — relatório executivo para a CEO com estrutura obrigatória de 4 seções e formato da tabela especificado. Direciona o modelo para o tipo exato de documento esperado.
O componente Action instrui o modelo a calcular a conta total, identificar desperdícios e construir o relatório na estrutura exata (sumário, tabela ordenada, roadmap em ondas, conclusão). O CSV é fornecido inline para trabalho direto nos dados reais.
O compomente Goal ancora a entrega na meta de negócio (15% = ~USD 6.000/mês) e no público-alvo (CEO), explicitando que o relatório deve habilitar decisão e deixar visíveis os tradeoffs operacionais.
